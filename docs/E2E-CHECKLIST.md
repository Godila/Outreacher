# E2E-чеклист приёмки MVP Outreacher

Выполнять на тестовом портале Б24 + тестовых ящиках (свой домен, 2 ящика на сабдомене). Каждому пункту — галочка и скрин/идентификатор при неудаче.

## 1. Установка и синк

- [ ] Приложение установлено на портале, `ONAPPINSTALL` обработан: в `b24_state` есть домен портала, токены не пустые.
- [ ] Через ≤15 минут (или после рестарта worker) контакты с email появились в `contacts` (сверить количество с CRM).
- [ ] RFM-поля заполнены: `last_deal_at`, `deals_count`, `has_active_deal` соответствуют сделкам CRM.

## 2. Сегмент и кампания

- [ ] Создан сегмент `{"last_deal_days_gte": 180, "deals_count_gte": 1}`.
- [ ] Создана кампания: 2 шага (шаг 2 delay 2 раб.дня, threaded), сегмент привязан.
- [ ] «Наполнить из сегмента»: в кампанию НЕ попали контакты в стоп-листе, с активными сделками и в других активных кампаниях.

## 3. Отправка

- [ ] Пул: добавлен ящик, лимит 10/день.
- [ ] Кампания запущена; в окне отправки письмо ушло (проверить ящик получателя, `List-Unsubscribe` и `Feedback-ID` в заголовках, футер с юрлицом и отпиской, UTM на ссылках).
- [ ] В таймлайне контакта Б24 появилось email-дело `[Outreacher] …` (Б24 НЕ отправлял письмо сам — копии нет).
- [ ] Повторный цикл scheduler не создал дубль письма (идемпотентность).

## 4. Ответы

- [ ] **positive** («Да, интересно, давайте созвонимся»): секвенция остановлена, в таймлайне комментарий, менеджеру создано дело «Ответ клиента — связаться» с deadline +4ч.
- [ ] **negative** («Не актуально»): секв остановлена, комментарий в таймлайне.
- [ ] **OOO** («В отпуске до 5 октября»): enrollment в `paused_ooo`, `ooo_until` распознан; после даты+1 раб.день секвенция возобновилась.
- [ ] **unsub** (клик по ссылке в письме): страница «Вы отписаны», email в `suppression` навсегда, статус enrollment `unsubscribed`, повторные кампании его не берут; one-click POST (эмуляция `List-Unsubscribe-Post`) возвращает 200.
- [ ] **unknown** (нейтральный текст): строка в инбоксе с жёлтой подсветкой; ручная разметка оператором применяет переходы.

## 5. Bounce

- [ ] Письмо на несуществующий адрес: SMTP 550 или NDR → статус `bounced`, email в `suppression` (hard_bounce), enrollment `bounced`.
- [ ] При 4xx (серый список) письмо ретраится ≤3 раз, затем `failed` с текстом ошибки.

## 6. Доставляемость (инфраструктура, один раз)

- [ ] mail-tester.com ≥ 9/10 с ящика кампании (SPF/DKIM/DMARC pass, PTR ok).
- [ ] Домен зарегистрирован в постмастере Mail.ru (FBL `Feedback-ID` работает) и в постмастере Яндекса.
- [ ] Прогрев: первые дни ≤ 5–10 писем, к концу второй недели 30–50/день на ящик.

## 7. Эксплуатация

- [ ] `/health` отвечает 200 c `db: true`; heartbeat воркера свежий.
- [ ] Бэкап: cron `pg_dump | gzip` + `gzip -t` (канон деплоя).
- [ ] Деплой: `alembic upgrade head` ДО `up -d`; после пересоздания web — restart nginx.
